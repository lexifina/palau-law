# § 1007. Grading of criminal conspiracy.
(a) A conspiracy to commit murder in any degree is a class A felony.
(b) Except as provided in subsection (a), a conspiracy to commit a class A felony is a class B felony.
(c) Except as provided in subsections (a) and (b), conspiracy to commit a crime is an offense of the same class and grade as the most serious offense that is an object of the conspiracy.
