# § 621. Classes of felonies.
(a) Apart from first and second degree murder, attempted first and second degree murder, and the offenses set out in chapter 21 of this Title, felonies defined by this Penal Code are classified, for sentencing purposes, into three classes, as follows:
(1) Class A felonies;
(2) Class B felonies, and
(3) Class C felonies.
(b) A felony is a class A, class B, or class C felony when it is so designated by this Penal Code. Except for first and second degree murder, attempted first and second degree murder, and the offenses set out in chapter 21 of this Title, a crime declared to be a felony, without specification of class, is a class C felony.
(c) A felony defined by any statute of the Republic of Palau other than this Penal Code shall constitute for the purpose of sentence a class C felony, except if another provision of law specifically defines a felony to be of a specified class as defined by this Penal Code, such felony shall be treated for the purpose of sentence as provided by this chapter for that class of felony.
