# § 1907. Extortion in the second degree.
(a) A person commits the offense of extortion in the second degree if the person commits extortion:
(1) of property, labor, or services the value of which exceeds fifty dollars ($50) during any twelve-month period; or
(2) as set forth in 17 PNC Section 1905(2).
(b) Extortion in the second degree is a class C felony.
